# 灵魂图鉴 · 测测你的灵魂对应哪位中国历史人物

四十道生活化的选择题，不考历史，只照见你。答题约五分钟，最后从十四位古人里，找到与你最接近的那一位。

在线体验：<https://wanghital.github.io/soul-quiz/>

## 玩法

- 题库共 80 道，每次随机抽取 40 道作答——题目全部取材于日常：吃饭、通勤、社交、情绪反应、兴趣偏好；重测会换题
- 每题四个选项，按八个性格维度计分：洞察、胆气、文心、情义、疏朗、锋芒、柔肠、兴致
- 综合八维形状匹配十四位古人，给出契合度、性格底色、匹配理由、隐藏优势与趣味彩蛋
- 结果卡为竖版长图比例，可直接截图分享到小红书、朋友圈

## 技术说明

单文件静态网页，HTML、CSS、JavaScript 全部内联，无后端、无外部图片依赖，字体走国内镜像，断网也能正常答题。评分在本地完成，作答数据不上传。

计分并非简单累加：先按题库基线把原始分转换成八维 z 值，再与人物向量做相关度匹配，并对主导维度加权，避免均衡型人格被极端型人格系统性压制。

## 声明

这是一次趣味人格游戏，不是历史考试，也不是心理诊断。结果仅供一笑，古人也只是镜子。
